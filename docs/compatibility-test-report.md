## 覆盖内容

- 三个独立权限的命令和 Tab 补全隔离、admin 子权限继承、显式子权限拒绝；普通玩家拒绝和 OP 显式拒绝还由单元测试验证。实服权限主体使用 Bukkit PermissibleBase / PermissionAttachment。
- 真实 PlaceholderAPI 注册、17 个新增键与旧键、未知键不解析、无玩家参数、异步读取、开关即时刷新、红石和卸载计数、停止清零、`/papi reload` 后仍可读取、完整 JVM 重启后的状态。单元测试另验证配置与运行状态区分、世界名去重、容量溢出和采样任务停止。
- 原有世界/实体/材料规则字段优先级、总开关和持久化、命名/乘客/书与笔保护、密集实体零上限及同 tick 失效实体排除。
- 旧音效别名，垃圾桶和密集实体菜单构造及图标更新；单元测试验证自定义物品堆叠上限。
- 定时切换真实红石块电源产生原生事件，验证 report 不抑制、忽略世界、suppress 上升沿抑制和下降沿放行、方块保留。

- 非法配置/参数、配置保存失败时保留状态、禁用时停止服务并取消任务。

## 本轮失败与修正

初轮使用旧接口编译的测试保护监听器在现代版本调用 `ChunkUnloadEvent.setCancelled`，产生 NoSuchMethodError；1.17.1 的新生成目标区块还出现重启标记为 AIR、首次关服后目标区块记录未落盘的问题。该初轮没有计入最终通过数，完整日志保留在附件 `earlier-attempts/permissions-initial/`。

修正仅位于测试探针：按 Cancellable 能力调用旧版取消接口；先让新生成区块激活，再保存基线、写入未保存标记、解除预热强加载并开始卸载验证。1.17.1 定向重测中，首次关服的区块文件含钻石块调色板，JVM 重启读取 DIAMOND_BLOCK。运行器也增加了插件/探针事件异常和链接错误检查。

重跑矩阵时，1.20.6 随机生成鸡骑士，乘客保护正确保留额外僵尸，导致固定数量场景的两项断言失败。探针现将随机坐骑移除、僵尸设为成年；乘客保护仍由另一个显式骑乘场景验证。定向重测 60/60 通过。另外，1.17.1 有一次重启停在服务端资源加载阶段，尚未加载插件，280 秒后超时并终止；原因未确定，独立完整重测通过。两项原始运行保留在 `earlier-attempts/matrix-retry/`。

最终表格按完整矩阵与定向重测中的有效运行汇总，每个版本均完成首启和 JVM 重启，具体来源见 manifest 的 `source_run`；无 PAPI 两个端点另外运行。失败、超时及重复运行不计入 685 项。全过程生产 JAR 未改动。

离线测试环境中，部分服务端日志含认证公钥网络请求失败、超平坦世界配置提示等消息；它们保留在原始日志中，不表述为全部日志无错误。最终有效运行没有检测到插件/探针的事件处理、启停或链接错误。

此前基础功能包的 60 项单元测试、405 项实服断言及 1.12.2 等待时间调整属于上一轮证据，单列在附件 `baseline-validation/`，不与本轮计数合并。

## 结论边界

本报告证明表列 Paper 构建、JDK 和 PAPI 组合的指定场景。没有测试每个补丁版本、Spigot 实服、Folia、混合核心、所有 PAPI 版本或第三方插件组合、真实在线玩家距离/观察区块、真实玩家 GUI 点击、全部自然红石电路或长期性能。缺少票据/强加载 API 的旧版按不适用处理，因此断言数不同。

有插件票据却无观察玩家 API 的版本仅对无玩家世界处理卸载。请求接受数不代表实际卸载数；测试另检查实际卸载事件和持久化。红石事件/抑制数不表示 CPU 耗时或 TPS 收益。详见 [兼容说明](compatibility.md) 和 [权限与占位符](permissions-placeholders.md)。
